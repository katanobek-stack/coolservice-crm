# Прошивка оборудования

Проекты в этой папке отделены от `web` и `functions`.

- `sim900a_diagnostics/` — одноразовая диагностическая прошивка ESP32 + SIM900A. Она не читает датчик, не обращается к CRM и не содержит ключей устройства.

## Рабочий контроллер ESP32 + SIM800C

Эта папка не является источником ключей устройства. Рабочая firmware хранится
отдельно; в CRM-репозитории остаются только эксплуатационные сведения.

- Плата: **ESP32 Dev Module**, Arduino ESP32 core 3.3.7.
- Модем: **SIM800C**, TinyGSM 0.12.0, `GovoroxSSLClient`.
- UART модема: ESP32 RX **GPIO21**, TX **GPIO22**, скорость **115200**.
- Включение модема: **PWRKEY GPIO27**.
- DS18B20: **GPIO13**.
- RTS, CTS, DTR и DCD не используются: не подключать и не включать software
  flow control без отдельного аппаратного изменения.
- Отправка: MQTT QoS 1 через bridge; telemetry содержит одну точку на сообщение.
- LittleFS используется как локальная стойкая очередь недоставленных telemetry
  точек. PUBACK от MQTT не означает получение CRM; запись удаляется только по
  логике firmware после подтверждённой публикации согласно её очереди.

Не добавляйте в эту папку `DEVICE_KEY`, MQTT password, APN password,
сертификаты с приватными ключами или заполненные `device_config.h`. Схему
питания модема и точную разводку изменяйте только после отдельного испытания.
