# Общие задачи ППЗ без сроков

Блок «Задачи без сроков» находится в ППЗ над существующим дневным планом.
Администратор и владелец назначают общую задачу одному или нескольким
существующим сотрудникам и видят все задачи с фильтром по сотруднику.
Сотрудники видят только свои назначения. «Приступить» фиксирует начало работы.
«Завершить для всех» убирает задачу из активных списков всех исполнителей,
сохраняя её в завершённых вместе с автором и серверным временем закрытия.
Повторный или одновременный запрос сохраняет первого закрывшего.

Документ ppzTasks/{id} хранит общий статус и массив assignees. Из браузера
доступно только чтение по правилам Firestore; изменения проходят через
savePpzTask в europe-west1. Менять статус может только назначенный исполнитель.
Прежние дневные планы, Telegram и задачи ремонта не меняются.

## Выпуск и проверка

Развернуть только firestore:rules и functions:savePpzTask, затем web.
Проверки: web typecheck/build, functions build; Firestore emulator с
functions/tests/ppzTasks.emulator.test.js и web/tests/firestore.rules.test.mjs.
Новые серверные тесты включены в test:daily-plans:emulator.

## Разовый перенос из ClickUp

scripts/import-ppz-tasks.js в functions принимает путь к локальному JSON:
projectId, meetingDate, nameMapping (имя -> существующий UID), tasks
(id, title, assignees как массив имён, taskId и необязательные commentId/description).
По умолчанию выполняется проверка без записи. Для записи нужны --execute
и --project=coolservice-crm. Сценарий проверяет реальные профили, атомарно
создаёт документы и сохраняет ссылку на источник. Повторный запуск не
перезаписывает существующие задачи, их статусы и отметки выполнения.
Назначения следует брать также из комментариев ClickUp: поле assignees
может быть пустым, хотя решение планёрки уже записано текстом.
ClickUp этим сценарием не изменяется.
